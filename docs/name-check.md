# Name check: "Course Keeper"

Date of the search: 2026-11-24. This is a research note, not legal advice.

## Result

Conflicts in other fields only. The search found no live trademark and no established software product named "Course Keeper" (or "CourseKeeper", "course-keeper") in developer tools or AI coding tools.

## Findings

| Area | Finding |
| --- | --- |
| US trademark | One "COURSE KEEPER" registration (serial 77723286) for golf accessories, classes 8 and 28, cancelled in 2016. Seen on an aggregator page, not verified against the USPTO database. |
| Similar marks | "COURSEKEY" is a live US mark for education software (classes 9 and 42). The name differs. |
| Other fields | "Course-Keeper" is a boat steering accessory sold by a Dutch company (course-keeper.com). |
| GitHub | About 20 small repositories use the name, most for course tracking in education. One small, inactive repository uses "Coursekeeper" for a control layer of an AI agent; it is the closest use. The organisation names `course-keeper` and `coursekeeper` are free. |
| Package registries | npm, PyPI and crates.io: `course-keeper` and `coursekeeper` are free. |
| Extension and app stores | VS Code Marketplace, Open VSX, JetBrains Marketplace, Apple App Store and Google Play: no product with this name. Chrome Web Store: one course-registration helper for one university. |
| Claude Code plugin marketplaces | No match in the two official marketplace files. |
| Domains | coursekeeper.com is parked for sale. coursekeeper.ai was registered in April 2026; its use is unknown. coursekeeper.dev and coursekeeper.io appear unregistered. |

## Not covered

- The USPTO, EUIPO and WIPO databases could not be queried by a program. A person must search "COURSE KEEPER" and "COURSEKEEPER" at https://tmsearch.uspto.gov/, https://euipo.europa.eu/eSearch/ and https://branddb.wipo.int/, live and dead marks, classes 9 and 42.
- National registers, for example the Benelux office for the Dutch product.
- Unregistered use, pending applications, and phonetic or translated variants.

## Before commercial use

For an open-source release the risk found is low. Before commercial use, or before filing a trademark, a clearance by a trademark attorney adds the register searches above, a judgment on confusion with near marks, and advice on whether the name is descriptive.
